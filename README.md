## Getting started

Be sure that C++ and CMake are installed on your machine to compile the source code.

Clone this repository with `git clone <url>`, then install necessary extensions for VS Code and finally compile and run the code to see the 2D UI and 3D base game (which is very very simplified).

## Purpose of this project

The purpose of this project is not to ship a full game and physics engine. 

No, the purpose is to ship the basics of 3D game engine rendering and 2D UI rendering within a simple C++ code base with essential libraries to work with 3D models, json configurations, gltf 3d model files, audio and more.

Then the single developer can clone or fork this 3D game engine and add their implementations and improvements.

I'll use this game engine for a incoming big project that I have in mind for a very long time. It'll involve heavy mathematical processing and equations to simulate something very special to me.

## Technologies & Standards

| Technology | Details |

| **Language** | C++17 |
| **Build System** | CMake |
| **Graphics API** | OpenGL |

| **OpenGL Loader** | GLEW |

| **Physics Engine** | Bullet Physics |
